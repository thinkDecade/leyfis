Brand usage guidelines
DO
Use LEYFIS in all-caps. Always.
Use #0A0F1C or #F7F8FA as backgrounds only
Keep clear space equal to icon height on all sides

DON'T
Never write Leyfis in mixed or lower case
Never rotate, stretch, or recolour the gate icon
Never place on coloured, photographic, or busy backgrounds
Never add drop shadows, glows, or gradients to the mark
Never use warm colours (gold, amber, red) in any context
